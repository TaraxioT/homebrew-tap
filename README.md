# TaraxioT Homebrew tap

Formulae for software published by [TaraxioT](https://github.com/TaraxioT).

| Formula | What it is |
| --- | --- |
| [`chargelight`](https://github.com/TaraxioT/chargelight) | Program the LED on your MagSafe charger from a shell, a script or an agent |

## Install

```sh
brew install taraxiot/tap/chargelight
```

Homebrew taps this repository automatically. To browse first:

```sh
brew tap taraxiot/tap
brew info chargelight
```
